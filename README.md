# Make the AI Judge Laugh: Cat Reviews Its Human

A one-star review from a house cat whose lap has been permanently occupied by a glowing rectangle — the laptop. The cat pays rent in purrs, gets evicted daily, and notes the rectangle does not even purr back.

`main.py` (Python stdlib only) writes exactly one line — a deadpan one-star cat review, under 200 characters — to `/output/entry.txt`.
